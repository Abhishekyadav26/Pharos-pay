## Overview
Scan & Pay is a seamless, user-friendly, that enables fast and secure token transfers using QR code technology on the Pharos.

## 🚀 Features
- Scan to Pay: Instantly scan QR codes to retrieve payment details.

- QR Generation: Generate and share your wallet QR for quick payments.

- Secure Token Transfers: Send Pharos tokens with full transaction visibility.

- Wallet Integration: Easily connect your Pharos-compatible wallet.

- Fast & Gas-Efficient: Built on the scalable and cost-effective Pharos blockchain.

 

## 📦 Tech Stack

- **Frontend**

## 🛠️ Getting Started

### Prerequisites
- Node.js (Latest LTS version)
- MetaMask or compatible Web3 wallet

### Installation

```bash
# Clone the repository
git clone https://github.com/Abhishekyadav26/Pharos-pay.git
cd Pharos-pay

# Install dependencies
npm install

# Run development server
npm run dev
```
